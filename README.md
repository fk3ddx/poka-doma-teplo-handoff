## Запуск

Клонировать репозиторий целиком либо выбрать **Code → Download ZIP** и распаковать. На Windows запустить `horror-project/game/START.cmd`. Нужен Node.js; все игровые ресурсы локальные.

Вручную:

```sh
cd horror-project/game
node server.mjs
```

Затем открыть http://127.0.0.1:4177/. Это локальный адрес, не опубликованный игровой сайт. [Подробное руководство](horror-project/game/README.md).

## Художественное направление

Fears to Fathom: Norwood Hitchhike и близкие инди-хорроры; уютная бабушкина квартира на верхнем этаже постсоветской пятиэтажки, мрачный туман за окном, постепенное нарушение безопасности. «Атаки на запоминание»: пережить смерть, вернуться назад и изменить действие благодаря памяти.

Браузер/Three.js, рабочее название и конкретные сюжетные события выбраны предыдущим агентом и могут быть пересмотрены. Новому агенту не следует автоматически считать эти решения требованиями пользователя.
