## Что положить в ImportInbox

Полный оригинальный `.unitypackage` Old Soviet Apartment vol.1, сохранив вложенный URP-пакет и архивы, либо ZIP экспортированного полного пакета с `.meta` и текстурами. Одного FBX без материалов/карт недостаточно. Пароли/токены/платёжные данные не нужны.

Папка `ImportInbox/` в корне репозитория создана. Исходники купленных ассетов не публиковать в открытом GitHub или source.zip. Для них зарезервирована игнорируемая папка `unity-game/Assets/ThirdPartyLicensed/`; первый осмотр/распаковка — в `AssetStaging/`. Импорт не должен перезаписать наши ProjectSettings/Packages. Производные материалы, текстуры и prefab с лицензированными данными также хранятся внутри этой папки. Код и реестр источников остаются отдельно.

## Проверки после получения (ещё НЕ выполнены)

1. Проверить архивы без запуска сторонних EXE/скриптов; читать инструкцию URP, состав и лицензии. Изолированный импорт в **6000.3.26f1**, без миграции рабочего проекта.
2. Сверить чайник/плиту/холодильник/двери/светильник с описанием. Проверить раздельные meshes/pivots/colliders, shader errors, material slots, текстуры и общий бюджет. Декоративные скрипты демо не переносить автоматически.
3. ScaleCheck: дверь0.8×2м, потолок2.5м, стол0.75м, сиденье0.45м, глаза1.55м; сравнивать конкретную модель техники с её прототипом. Реальные габариты, не масштабирование «на глаз».
4. Сборка кухни/куска прихожей, свет/блэкаут по VIBE5.1, записанный бытовой фон, чайник, один скример. Другие комнаты не менять.
5. Лично пройти меню→конец в Windows-билде. Скриншоты четырёх режимов, замер перехода в блэкаут, проверка взаимодействия/стыков/камеры/аудио, DEVLOG с честными ограничениями. Только потом показывать срез заказчику.
