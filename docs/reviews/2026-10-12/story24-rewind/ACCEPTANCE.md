# Story24 — критерии настоящей перемотки (§6.1)

База: cce6742, отдельная playable/Story23 и ZIP не изменяются. Предыдущий ход — подтверждённый прогресс: выдана проверенная Windows preview, цель не завершена.

Claude реализует StoryDirector/ScenarioSound/Replay и внутреннюю QA. Codex проверяет код, собирает и запускает Windows с беззвучным -audio-capture; возвращает настоящие PNG и дефекты через Codex. Не вносить одновременно несовместимые изменения этих исходников.

## Сценарные требования

1. Общая сцена 8–10 секунд активного игрового времени. Первая секунда чёрная и тихая.
2. Настоящие события первой ночи идут в обратной хронологии: балкон, телефон/стук, телевизор, свет. Их нельзя заменять описательными титрами.
3. Обратные ускоренные звуки; нарастающее тиканье часов. Многоканальный PCM переворачивается по аудиокадрам, не меняя каналы местами.
4. Короткие воспоминания о доступных вечерних событиях. Отсутствующие ещё сцены (например, частицы побелки) остаются явно открытыми, а не считаются выполненными.
5. Белая вспышка, дрожащий стоп-кадр и PLAY. После этого настоящее начало ночи 2.

## Проверка состояния

- Пауза в середине останавливает продвижение реплея; выход с паузы продолжает его.
- Нельзя оставлять scripted/locked/положение створок, камеру, scale, control или звук в режиме реплея после отмены/новой игры/перехода Night2.
- Ограничение памяти у записи; не накапливать кадры бесконечно. Замер времени, числа записей и занятой памяти в QA.
- Световые объекты не переключаются через SetActive ради перемотки; используются параметры intensity и существующий принятый рендер.
- PNG должны показывать реальные состояния, а тест порядка — сравнивать записанную и проигранную хронологию. Наличие заданного числа скриншотов само по себе не доказывает обратное воспроизведение.
- В README перечислить то, чего в записи ещё нет, и пределы теста. Финальное качество и прослушивание не выводятся из успешного автотеста.
