# 13 — Готовая Гостья (OGA, CC0) и остановка после новостей

## Модель
**Выбрано:** «3D Horror Game Monster» — City Building Game Art (HorrorGameMaker.com), https://opengameart.org/content/3d-horror-game-monster.
- Лицензия **CC0** — так указано в поле лицензии на странице. README в архиве: кредит «HorrorGameMaker.com» по желанию, добавлен в `CREDITS-GUEST.md`.
- Скачано мной напрямую с OpenGameArt (`Poses.zip`, `Colors.zip`). Ничего не обходилось.

**PSX Horror Entity не взят:**
- явной лицензии на странице нет, только «completely free» в комментарии автора;
- модель — фан-арт по дизайну Platiboo (Scissormen): человек-ножницы с лезвием, это не Гостья.

**Что в репо** (`Art/ReadyModels/Sketchfab/GuestBody|GuestClaw` — папка названа исторически, источник OGA):
- `GuestBody.fbx` 1.9 МБ: меш Creature1, **3584 треугольника**, риг 70 костей, рост 1.85 м.
  - Клипы `…|Idle`, `…|Walk`, `…|Run`, `…|Jump`. `GuestInstaller` выбирает их по словам idle / walk / run.
  - Риг, rest pose и bind poses не тронуты. Масштаб под прокси задаёт Unity.
- Текстуры 1024: albedo и normal расцветки **Blue** — самая серая из четырёх (сравнение в `13/sheet.png`).
- `GuestClaw.fbx`: **правое предплечье и кисть, вырезанные из того же меша** по весам `joint11.001` и потомков, в bind pose, 0.46 м.
- Превью Cycles: `13/prev-Idle.png`, `13/prev-Walk.png`, `13/prev-claw.png`.
- Повтор сборки:
  ```
  blender -b --python tools/art/merge_oga_monster.py -- <Poses> <out.glb> <dir с albedo.png, normal.png>
  blender -b --python tools/art/prepare_guest.py -- <out.glb> --source … --author … --license CC0-1.0 --claw from-body --hand-bones joint11.001
  ```

**Честно о недостатках** (решение по виду — за Димой):
- Много крови на коже. Сильно мужской торс. Голова — безглазый «капюшон» с пастью, бабушкиного лица у неё нет.
- Кисть низкополигональная, пальцы короткие. Для крупного плана 7.4 «длинные серые пальцы, ногти у висков» это слабо.
- Анимации ползания нет. Режим Crawl (охота 22:06) возьмёт первый доступный клип, тело при этом стоит. Нужна поза или отдельный клип.

**У Codex:**
1. `Ataka.Editor.GuestInstaller.Install`, затем `ScenarioBuilder.Build`.
2. Кадры DeathFull/DeathShort и Hunt.
3. Калибровка `FaceTearDeath.clawEuler` / `clawLength` по кадру.

## Остановка после новостей (story15-flow-a)
Гипотеза Codex подтвердилась офлайн на `colliders-serialized.json`:
- автопилот после «Включить «Рубин»» стоит в (5.70; 3.28);
- путь бабушки Armchair→Door в этом месте не обходится — между диваном/столиком и тумбой ТВ нет места на две капсулы;
- `PlayerInTheWay` держал её вечно, следующей задачи не было.

**Runtime (коллизии не ослаблены):**
1. Если игрок стоит на пути дольше 1.2 с, она пересчитывает маршрут, **обходя его капсулу** (r = 0.22 + радиус CharacterController + 0.08). Офлайн: из (5.3; 1.6) и (5.5; 2.6) обход есть, минимум 0.8 м до игрока.
2. Если обхода нет (проём, место у ТВ), она ждёт и пробует снова каждые 1.2 с. Через 4 с говорит: «Мишаня, пропусти-ка».

**QA:**
- `STALL?` — каждые 20 с без новой задачи, титра или действия пишется глава, задача, позиция игрока, `gran (x,y,z) walking to X waiting N s`, сцена и открытые действия.
- `QA-YIELD` — если она ждёт дольше 2.5 с, автопилот отходит. Он встаёт в проверенную свободную точку, дальнюю от её линии к цели: точки проверены офлайн на реальных коллайдерах. Переход пишется в отчёт.
