# Claude — проходимая игра целиком (ветка `claude/playable-complete` от Codex `9424136`)

Цель — игрок запускает игру из меню и проходит всю историю SCENARIO до финала без QA-аргументов и телепортов. Это **код**: я ни разу не запускал Unity. Все runtime-скрипты Scenario собираются компилятором C# против `UnityEngine` (CoreModule, IMGUI, TextRendering 2020.3) и заглушек для InputSystem, Cinemachine, Timeline, URP, Physics, Animation и Audio. Ошибок 0. Это не проверка игры и не художественная приёмка.

## Порядок у Codex
1. `git am pc-0*.patch` или `git am pc-all.patch` на `9424136`.
2. Blender: `prepare_guest.py -- <файл существа> --source … --author … --license … --claw from-body` (кандидаты с прямой загрузкой — в 09) и `prepare_story_props.py -- <загрузки>`. Poly Haven скрипт качает сам.
3. Unity: `Ataka.Editor.ScenarioAudioBuilder.InstallAndBuild` (банк с бытовыми звуками), `Ataka.Editor.GuestInstaller.Install`, затем `Ataka.Editor.StoryPropsInstaller.Install`, затем `ScenarioBuilder.Build`. Без ассетов установщики пишут предупреждения, игра работает на временных объектах.
4. Проверки:
   - EditMode-тесты;
   - `-scenario-smoke` (петля и погоня, как раньше);
   - `-story-smoke <dir>` (пролог → петля);
   - `-story-smoke <dir> -story-from Finale`;
   - **ручное прохождение с меню** — человеком, это главное.
5. Калибровка по кадрам: `FaceTearDeath.clawEuler` и `clawLength`; координаты действий и предметов в `StoryDirector`, `StoryPropsInstaller.Places`.

## Не проверено мной
Ни одного запуска. Координаты действий и мебели взяты из плана и кода, без кадров. Бабушка ходит A\* по сетке занятости её капсулы (11), ждёт игрока и сама открывает незапертые двери. Это не NavMesh: подъёма по ступеням и обхода движущихся препятствий нет. Тайминги, ощущение и звук — только по чтению SCENARIO, без прослушивания.
