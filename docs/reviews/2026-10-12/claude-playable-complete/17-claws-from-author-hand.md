# 17 — Длинные чёрные когти из авторской кисти (кандидат, ждёт решения Димы)

Запрос Димы: длинные чёрные когти. Codex: «готовая лицензированная рука или доработка пропорций авторской кисти без новых примитивов». Готовой руки с когтями и прямой загрузкой нет: на OpenGameArt по запросам claw / hand / monster hand нашлись только молотки, кости и ящер. Поэтому сделана доработка авторской кисти.

## Что сделано (`prepare_guest.py --claws 3.2,0.2`)
- У каждого из 10 пальцев (`--wrists joint13,joint13.001`) берётся **последняя фаланга с весами**.
- Её вершины за суставом **сдвинуты вдоль пальца в 3.2 раза** и **сужены к кончику до 20 %** толщины.
- Грани когтя получают отдельный материал **Claw**: почти чёрный, roughness 0.25, то есть с блеском.
  - Если грань хотя бы наполовину лежит на когте или доходит до его внешней половины, она тоже чёрная.
  - Итого 280 вершин и 243 грани.
- **Новой геометрии нет:** только перемещение авторских вершин и назначение материала.
- **Суставы, веса, риг, bind poses и анимации не тронуты.** Коготь движется вместе с последней фалангой в Idle, Walk, Run и Jump.
- `GuestClaw.fbx` (крупный план 7.4) по-прежнему вырезан из того же тела, поэтому когти у него те же.
- В обоих FBX по 2 материала, имена совпадают с manifest (`VERIFY OK`). `GuestInstaller` сопоставляет материалы по имени, его менять не нужно.

**Отброшено:** сначала я пробовал удлинять пальцы масштабом костей. После glTF-импорта оси костей условные, растяжение шло вкось — `17/hand-before-bone-scale-attempt.png`.

## Честно
- Сами пальцы не удлинены, длиннее стали только последние фаланги-когти. «Длинные серые пальцы» SCENARIO это выполняет частично.
- Кожа кисти по-прежнему красная от крови текстуры.
- Это кандидат: **принимает Дима** по кадрам смерти из Unity.
- Повтор сборки:
  ```
  blender -b --python tools/art/prepare_guest.py -- <guest_oga.glb> --source … --author … --license CC0-1.0 --claw from-body --hand-bones joint11.001 --claws 3.2,0.2
  ```
  Первое число — длина когтя, второе — толщина кончика.
