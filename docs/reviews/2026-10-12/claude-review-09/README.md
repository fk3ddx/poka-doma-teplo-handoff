## Принято
Трюмо читается, масштаб правильный. VEF узнаваем и виден в зеркале. Грязные зелёные сапоги и тапки стоят естественно. Вешалка теперь обращена крючками в комнату на1.65м.

## P0 зеркало
В lap1-01/hall-mirror отражение бледное серо-голубое, ярче комнаты: экран/окно. В тёплом режиме тоже холоднее/бледнее. Claude предположил linear/sRGB или двойной постпроцесс; это гипотеза, код уже выключает renderPostProcessing и использует ARGBHalf. Проверять фактический render/shadows/color path, не записывать гипотезу как найденную причину.

Решение Claude на этот этап: все три секции — мутное старое зеркало на reflection probe, без planar, пока нет модели Миши. Боковые секции всегда probe, одна плоскость для них неверна. Позднее отдельная задача — центральное planar вместе с Мишей (SCENARIO175: аляска/шапка, затем свитер). Внешность Миши выбирает Дима. Грейдинг/VHS один раз основной камерой, стекло отражает примерно0.8. Проверка: в круге1 средняя яркость зеркала не выше соседней стены при том же свете; чёрный предмет не становится светлым.

## Фонарик
В обычной и тёплой диагностике внутри чёрная дыра. Свет НЕ менять. Стекло поставить3–4см за линией створки у переднего края, разворот около30° стеклом в коридор к бра прихожейБ. Рефлектор/стекло metallic1/smoothness~.9, серый или оливковый светлее корпус. Probe прихожейА должен учитывать бра. Нужен отражённый блик, не новый источник.

Необязательная готовая замена: Sketchfab Dynamo handheld flashlight / pajamakeke, заявленоCC-BY/~2k граней — точную ссылку и лицензию ещё надо проверить. Текущий signal_flashlight военный. Лично Дима проверит нахождение фонаря в темноте.

## Взаимодействия
Прицеленный луч сначала выбирает объект, чей коллайдер задет. Если не задет никто — меньший угол к центру экрана. «Закрыто» у двери только когда луч попал в дверь. Это убирает ложную подсказку на телефоне.

## Дальше по сценарию, без нового сюжета
1. Потолок: убрать бугристый скальный материал, побелка+галтель для квартиры; принятый свет не менять.
2. Пол: коричневый линолеум SCENARIO вместо паркета; красно-коричневая полосатая тканая дорожка~0.8×3.0м от входа к прихожейБ (фактурная плоскость).
3. Стены под дерево, плинтус по SCENARIO.
4. Вешалка: Cozy Winter Shawl / AwesomeAmbz (заявленоCC-BY/~5k); Ushanka Hat / EvesStudio2008 (CC-BY/~1.9k), на полку. Дедово пальто готового висящего пока нет: кандидаты Pekka Tiilikainen's Overcoat / urheilumuseo (музейный скан,CC-BY/60k), Coat / Lovric (6k). Проверить превью/ссылки/лицензии самостоятельно; не выдумывать ссылки. Если не повесить правдоподобно, пока шаль+ушанка.
5. Кухонная дверь белая с рифлёным стеклом; архитектура.
6. Щиток с двумя пробками на1.7м у входа, бумажка «свет / розетки»; архитектура.
7. Плафон-таблетка, матовый диск на потолке.

Порядок Claude: зеркало → фонарь → приоритет → потолок/пол/дорожка → вешалка → двери/щиток. Не возвращаться к подушкам.

Дима оценивает нахождение фонаря, внешность Миши позднее, общий вайб после этих исправлений. Прихожая целиком НЕ принята.
