Windows story22-build-b, 145/145 настоящих PNG. Полная и короткая смерть в двух комнатах при входном pitch 0/+60/-60, после висения/ползания; затем реальная последовательность первой ночи с 22:00 до смерти (до смерти время ускорено). Ошибок runtime/проверки кадрирования нет. В tests проверяется готовая голова через WorldToViewportPoint, а не только логический скелет.

Исправлены: наклон всего монстра от взгляда игрока, остаточное смещение ready model после ground clamp. Сохраняется исходное локальное положение установленной модели, после окончания ползания оно возвращается.

Это проверка постановки и состояния, не художественная приёмка: мужской монстр-кандидат не соответствует финальной Гостье с лицом бабушки, руки и страшность требуют оценки игроком. Звук захвачен без воспроизведения, аудиоприёмка не заявляется.
