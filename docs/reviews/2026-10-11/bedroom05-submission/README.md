# Пакет05 — контрольная версия, НЕ готовый релиз

Все 8 групп review04 внесены. Поза/верёвка и принятый LightLab не менялись. Матрица13 кадров и полный обзор46 кадров приложены в исходном разрешении1280×720.

## Проверки и оставшиеся дефекты
- Windows-сборка BedroomArt05.ApplyAndBuild успешна. Геометрический аудит входа капсулой0.44м при закрытом/открытом шкафе PASS.
- bedroom05-full: FAIL на первом круге — точка взаимодействия шкафа; исправлена.
- bedroom05-routefix-full: дошёл до6 круга, FAIL/1exception — ссылка на удалённую дверь ванной в chaseOverlap; исправлена пересборкой списка по исходному объёму.
- bedroom05-delivery-full: FAIL на выходе5 круга, errors=0. Полотно двери под ковром при открывании толкает игрока из(.86,.01,3.75) в(.24,.02,3.53), герой застревает у стены/тумбы. Все события1–5 перед этим прошли. Нужен реальный фикс столкновений створки, не маскировка маршрутом автотеста.
- bedroom05-chase-check: изолированный chase-only FAIL ожидания смерти/перезапуска, errors=0. Причина пока не установлена; нельзя считать проверку погони успешной.
- art-review-05-delivery:46 исходных кадров, постановочная QA-съёмка, не прохождение.
- bedroom05-delivery-matrix:2 точки×6 моментов+боковая диагностика. Боковой кадр с временным нейтральным светом и скрытыми стенами; не обычный вид.
- Все проверки silent audio-capture. Человеческого прохождения, прослушивания и приёмки не было.

## Что прошу Claude оценить
1. Решение для открывающейся двери под ковром: сейчас Slerp вращает коллайдер сквозь капсулу и выдавливает её. Предлагаю останавливать створку перед капсулой, возобновлять после отхода; сохранить физическую дверь и не двигать камеру насильно. Нужна рекомендация расстановки/траектории.
2. Подушки на ребре и кружево ещё читаются почти чёрными в реальном свете, хотя текстура белая. Не принимать только по коду.
3. Лампадка — временный готовый ceramic_vase_01, узнаваемость плохая. Иконы тёмные; исходный источник теперь spot, но полка всё ещё ярко-красная.
4. Фасад шифоньера после вписывания в1.0×.55×1.90м, открытые створки и проход.
5. Лужица выглядит чёрным пятном, в5.1 теряется; капля/блик/след требуют оценки по оригиналам.
6. Белая дверь, ковёр, обои, потолочный патрон и покрывало: жёсткое арт-ревью, список конкретных правок. Остальные комнаты прежние, НЕ заявлены готовыми.
