# Реальные кадры M1

15 PNG получены из видимого Windows-плеера Unity на GTX 1650 SUPER / D3D12, 1920×1080. Никакой дорисовки кадров. Хеши — capture-provenance.json. result.json содержит короткий замер с лимитом 60 FPS и отдельные интервалы переключения света; он не заменяет ручное прохождение. test-results.json содержит именованные результаты автоматических тестов. Попарное сравнение с официальными кадрами Fears to Fathom — ../compare.html.
