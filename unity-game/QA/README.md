# Реальные кадры и проверки M0

Кадры 1280×720 получены из Windows-плеера Unity 6000.3.26f1 на GTX 1650 SUPER. Они не являются концепт-артом и не показывают целевую графику M1.

- `01-menu.png` — меню.
- `02-living.png` — техническая геометрия зала.
- `03-kitchen.png` — кухня, объём холодильника и спички.
- `04-courtyard.png` — высота пятого этажа и объёмы внешних домов.
- `05-lights-off.png` — коридор с выключенными источниками.
- `test-results.json` — 17 успешных тестов без персональных полей исходного XML.
- `result.json` — результат автоматического запуска плеера; условия и ограничения замера описаны в `../TESTING.md`.
