# Источники ресурсов Unity M0

- Исходный C#-код, тестовая геометрия и шейдер `Ataka/SubtleVHS` созданы для этого проекта.
- `ProjectSettings/` и `Assets/Settings/` первоначально взяты из официального шаблона Unity `com.unity.template.3d-cross-platform` 17.0.14, поставляемого с Unity 6000.3.26f1. Это настройки движка и URP, а не модели или текстуры сторонних художников. Их использование подчиняется условиям Unity.
- URP, Input System, Test Framework и остальные зависимости перечислены в `Packages/manifest.json` и `packages-lock.json`; их лицензии содержатся в соответствующих пакетах Package Manager.
- В M0 не перенесены голоса с неопределённой лицензией из прежней браузерной версии. В этом техническом каркасе нет озвучки, музыки, моделей персонажей или заимствованных материалов референсных игр.
- Fears to Fathom, P.T. и другие игры из общего брифа служат референсами. Их ресурсы не входят в Unity M0.
