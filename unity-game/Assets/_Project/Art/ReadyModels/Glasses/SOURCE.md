# Ready round spectacles

Original asset: MRT / MargaretToigo, CC0. Original OBJ/MHCLO headers retained.
https://static.makehumancommunity.org/assets/assetpacks/glasses01.html

Used as a loose bedside prop. Original geometry and UV retained; uniformly scaled to 14cm width, recentered to bottom-center, exported to FBX. Source MH material is not a Unity material; texture alpha and visibility require in-engine verification. No character, rig or rejected MPFB appearance is restored.
