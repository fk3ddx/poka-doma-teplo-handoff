# Проверка масштаба готовых ассетов

Создано и проверено 2026-10-11 на Unity6000.3.26f1. Код: `Assets/_Project/Scripts/Core/RealSize.cs`, `Assets/_Project/Editor/RealSizeAudit.cs`. Меню: **Ataka → Kitchen → Check selected object scale**.

Это инструмент импорта, не моделирование. Он не создаёт игровые меши, не меняет исходники и не выполняет измерения каждый кадр. Проверка читает реальные вершины через editor-only `MeshUtility.AcquireReadOnlyMeshData`, включая mesh с Read/Write off. Unity API: https://docs.unity3d.com/6000.0/Documentation/ScriptReference/MeshUtility.AcquireReadOnlyMeshData.html .

## Применение после импорта

1. На корень одного готового предмета добавить RealSize.
2. В `parts` явно выбрать MeshFilter частей этого предмета; только один нужный LOD. Не включать комнату, тени, соседние предметы, открытые дверцы в изменённой позе.
3. В `expectedMetres` задать размеры в метрах вдоль осей корня X/Y/Z. Ноль означает неизвестную/непроверяемую ось. Хотя бы один размер обязателен. Reference — источник размеров (прототип/измеренный референс/стандарт VIBE).
4. Допуск максимум15%. Выделить корень и запустить меню. Сначала исправлять неправильные единицы импорта; не растягивать весь интерьер, чтобы подогнать отдельный предмет.

Проверка учитывает scale всей иерархии и реальные положения вершин, но убирает общий поворот предмета, чтобы не путать диагональный мировой AABB с его физической шириной. При деформации из-за non-uniform scale родителя размеры изменятся — это полезный сигнал ошибки. Поддерживаются статические MeshFilter; скелетные персонажи не входят в текущую задачу.

## Фактическая проверка

`Ataka.Tests.RealSizeTests`, EditMode: **7 passed,0 failed**, XML `TestResults/KitchenScale.xml`.

Покрытие: поворот не раздувает размеры; масштаб родителя учитывается; завышенный импортный bounds игнорируется в пользу вершин; Read/Write-off читается без изменения source; разнесённые части дают полный размер; неизвестные габариты/пустые части/нет ссылки/допуск больше15% не получают ложный PASS; mesh чужого объекта отклоняется.

Тестовые координаты синтетические и существуют только внутри тестов. Кухонные модели ещё не получены; их реальный масштаб, коллизии и визуальный вид этим отчётом не подтверждаются. ScaleCheck-сцена с готовыми предметами будет собрана после импорта. Самостоятельных моделей мебели/техники не добавлено. Игровые сцены и остальные комнаты в этом проходе не изменены.
