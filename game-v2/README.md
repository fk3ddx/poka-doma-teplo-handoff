# Атака на запоминание — пролог «У бабушки»

Камерный хоррор от первого лица в духе Fears to Fathom. Ноябрь 1996-го, пятый этаж хрущёвки, бабушкина квартира. Пересобран с нуля.

## Как запустить

**Проще всего:** открыть `Ataka-na-zapominanie.html` двойным кликом (Chrome / Edge / Firefox). Всё внутри одного файла, интернет и Node.js не нужны. Первая загрузка — 5–15 секунд.

Играть в наушниках. Если тормозит — Настройки → Качество → «низкое».

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | смотреть |
| W A S D | идти |
| Shift | быстрее |
| E / ЛКМ | действие |
| 1, 2 | выбор ответа в разговоре |
| C (удерживать) | закрыть глаза |
| F (нажимать несколько раз) | фонарик-жучок: подкачать |
| Esc | пауза |

## Что в прологе

1. Подъезд, квартира, тёплый вечер. Обычные дела: разуться, чайник на газу, помигать бабушке светом в окно напротив, телевизор, пирожок, кресло.
2. В 22:00 концерт прерывается. Дальше — «атака на запоминание».
3. Смерть не конец: время откатывается назад, ты помнишь, что было. Квартира с каждым разом чуть другая.

Длительность — примерно 12–20 минут, зависит от числа смертей.

## Для разработки

```
npm install --include=dev
npm run dev            # http://127.0.0.1:5173
npm run build:single   # dist-single/index.html — один файл
node tools/fetch-assets.mjs   # заново скачать CC0-ресурсы Poly Haven
node tools/make-voices.mjs    # заново синтезировать голоса (нужен Piper TTS в ~/tts)
```

Код: `src/core` — движок (рендер, ввод, звук, интерфейс), `src/world` — квартира, двор, предметы, `src/game` — сценарий, существо, предметы в руках.

## Ресурсы и лицензии

- Three.js, N8AO — MIT. Шрифты PT Mono / PT Serif — OFL.
- Модели и текстуры — Poly Haven, CC0 (список в `src/assets/CREDITS.json`).
- Обои, ковры, клеёнка, книги, фото, телевизор, мебель, двор — процедурные, созданы в этом проекте.
- Все звуки и музыка синтезируются в коде.
- Голоса — синтез речи Piper (голоса ru_RU irina / denis). У датасета голоса irina лицензия указана как «неизвестна» — **для публичного релиза голоса нужно заменить на записанных актёров**.
