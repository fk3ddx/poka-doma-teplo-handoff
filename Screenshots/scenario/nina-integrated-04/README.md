# Пятый круг: текущая постановка для ревью

Целевой автоматический прогон Windows, НЕ полное прохождение. result.json: passed=true, errors=0, lap=5, chase=false. E открывает дверь; игрок входит, проверяются видимость тела и начало сцены. Успех технического теста НЕ означает художественную готовность. Все 14 кадров включены без отбора. Свет и изображения не корректировались после захвата. Звук записан без вывода через колонки.

Особое внимание: дверной проём/шкаф, поза/подвес, ноги 1.1, подъём 2.6, поворот 3.6, темнота 4.6, исчезновение 5.1. Предыдущий полный прогон 03 остановился у пятого круга — известная неудачная проверка.
