# Пока дома тепло — играбельный пролог

Рабочая версия от 10 октября 2026. Оригинальная история: пятый этаж, бабушкина квартира, мокрый снег и повторяющийся вечер. Это конечный пролог с возможностью продолжить осмотр после финала; не полный коммерческий эпизод. Название и сюжетные подробности пока рабочие.

## Запустить

На этом компьютере дважды открыть **START.cmd**. Скрипт поднимет локальный сервер и откроет игру в браузере. Сеть для игры не нужна: движок, модели и текстуры лежат в папке. Нужны клавиатура, мышь и браузер с WebGL 2 (актуальные Chrome/Edge). Сервер слушает только 127.0.0.1, ничего не публикуется.

Вручную: `node server.mjs` из этой папки, затем http://127.0.0.1:4177/. При переносе на другой компьютер требуется Node.js LTS с официального nodejs.org. HTML нельзя просто открыть двойным щелчком: загрузке модулей нужен локальный сервер. Браузер можно развернуть на весь экран клавишей F11.

## Управление

- WASD — встать с дивана и ходить; мышь — осматриваться.
- E — действие по подсказке, следующая реплика, убрать записку.
- Esc — пауза. Если браузер не захватил мышь, нажать на игровую область; можно осматриваться с зажатой кнопкой мыши.
- В портативной игре A/D или стрелки — движение.
- Настройки: звук, чувствительность, яркость, разрешение, лёгкий VHS, дополнительное зерно и покачивание камеры. VHS включён по умолчанию, покачивание выключено. Текст интерфейса не проходит через VHS.

Сохранения и настройки — localStorage этого браузера. Между разными браузерами они автоматически не переносятся. Удаление данных сайта удалит сохранение. История сохраняется на границах сцен; продолжение во время нападения возвращает к предупреждению.

## Содержание и границы версии

Есть спокойное начало с кофе, запиской, звонком, видом из окна и необязательной мини-игрой; разговор у двери; проверка крана; сверхъестественное предупреждение; гибель с откатом; осмысленное спасение; изменение квартиры и финальный разговор. Первое нападение не начинается сразу после появления. Можно выжить с первой попытки. После гибели длинное бытовое вступление не повторяется.

Диалоги текстовые; записанной актёрской озвучки и анимированной соседки пока нет. Звуки и короткая музыкальная последовательность синтезируются. Глазок пока передаёт наблюдение текстом и виньеткой; отдельной детализированной площадки за ним нет. Это заметные задачи следующей итерации. Продолжительность 8–12 минут — оценка с учётом чтения, не независимый замер. Художественный уровень пользователь ещё не утвердил.

## Проверка и разработка

`node tests/story.test.mjs` — проверки сюжетных условий, петель и сохранений. URL `?debug=1` включает явно обозначенные служебные кнопки для ракурсов и ускоренного времени; обычный запуск их не содержит. Кнопка сохранения кадра выгружает текущую 3D-картинку без служебного интерфейса.

`tests/browser.cjs` / `tests/visual.cjs` — ранние локальные сценарии Playwright, привязанные к установленным путям этого ПК; это не переносимая система CI. После художественной переработки дополнительная проверка проводится в браузере. Результаты и ограничения — в ../11-build-status.md.

Ресурсы и источники: ASSETS.md. Главная память проекта: ../MEMORY.md. Разбор реальных игровых кадров: ../10-visual-research.md.
