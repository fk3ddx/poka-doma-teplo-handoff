# Продолжение проекта

Перед содержательной работой прочитать MEMORY.md и 08-decisions.md, затем нужный тематический документ. Последние уточнения пользователя важнее старых вариантов.

Сохранять в MEMORY.md актуальный замысел, принятые решения, фактический статус и следующий шаг. Предложения явно отличать от решений пользователя. Исследование по источникам не выдавать за собственное прохождение, концепт-арты — за готовую игру.

Архивные изображения не удалять и не подменять без необходимости; новые варианты сохранять с новым номером. Актуальную подборку обновлять в 05-concepts.md. Все важные пользовательские исправления переносить в документацию.

Корневые ограничения проекта продолжают действовать: sources/ и синхронизированные материалы только для чтения; исходный корневой AGENTS.md не менять.
